## Три вещи, без которых сразу споткнёшься

1. **Боевая база с компьютера владельца недоступна.** VPN incy перехватывает соединения. Проверки идут на своей базе: Postgres.app, база `chaevye`, схема `test`. Поднять, если погашена:
   `/Applications/Postgres.app/Contents/Versions/17/bin/pg_ctl -D "$HOME/Library/Application Support/Postgres/var-17" -l "$HOME/Library/Application Support/Postgres/var-17/server.log" start`

2. **Выкладка приложения смены кладёт его на несколько минут.** Только днём, вне смены. Смена работает с ~12:00 до 3 ночи, в пятницу и субботу до 6 утра. Выкладка бэк-офиса и читателя безопасна в любое время — это отдельные приложения.

3. **Ветку `master` трогать нельзя без нужды** — Amvera собирает боевое приложение смены только из неё. Работаем в `main`.

## Как поднять на своём компьютере

```bash
cd "/Users/user/Documents/Невский/mini-app" && npm run dev      # смена, порт 3000
cd "/Users/user/Documents/Невский/manager-app" && npm run dev   # бэк-офис, порт 3100
```

Вход в бэк-офис на локальной базе заведён: логин `vika`, роль владельца. Пароль спросить у владельца или завести нового человека:
`cd manager-app && npm run manager:add -- "Имя" логин owner`
