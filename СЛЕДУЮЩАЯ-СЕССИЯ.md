**Два решения владельца 07.08.2026, которые легко нарушить по незнанию:**

1. **Бэк-офис — про начисления, а не про выплату.** Питания на экранах нет, колонка называется «начислено» = заработок минус доли. Но **из расчёта питание не убрано**: убрать значило бы показывать в двух приложениях разные деньги одному человеку.
2. **Смены не пропадают.** На экране сотрудника вечер, когда заведение работало, а человек — нет, стоит с пометкой «не в смене». Это требование, а не украшение: без него три смены за месяц выглядят как десять.
3. **Динамика — это сравнение с коллегами того же вечера**, а не с собственным средним и не абсолютная сумма. Абсолютная сумма говорит о людности зала: в слабый вторник мало собирают все. Не менять обратно, не поняв этого.

## Пять вещей, без которых сразу споткнёшься

1. **Боевая база с компьютера владельца недоступна.** VPN incy перехватывает соединения. Проверки идут на своей базе: Postgres.app, база `chaevye`, схема `test`. Поднять, если погашена:
   `/Applications/Postgres.app/Contents/Versions/17/bin/pg_ctl -D "$HOME/Library/Application Support/Postgres/var-17" -l "$HOME/Library/Application Support/Postgres/var-17/server.log" start`

2. **Локальная база пустая, пока не насочинишь.** `cd manager-app && npm run seed` кладёт 10 смен за две недели с разным составом — на них видно и правки, и динамику по людям. Александра 5 августа заработала ровно 1 250 ₽, на полсотни ниже порога: добавь ей 50 ₽ правкой и увидишь «мёртвую зону».

3. **Правила деления денег лежат копиями в двух приложениях.** Правишь `mini-app/src/lib/split.ts` — сразу `cd manager-app && npm run copies`, иначе бэк-офис не запустится. Так задумано: молча разошедшиеся правила показывали бы в предпросмотре не те деньги, которые люди получат.

4. **Выкладка приложения смены кладёт его на несколько минут.** Только днём, вне смены. Смена работает с ~12:00 до 3 ночи, в пятницу и субботу до 6 утра. Выкладка бэк-офиса и читателя безопасна в любое время — это отдельные приложения.

5. **Ветку `master` трогать нельзя без нужды** — Amvera собирает боевое приложение смены только из неё. Работаем в `main`.

## Как поднять на своём компьютере

```bash
cd "/Users/user/Documents/Невский/mini-app" && npm run dev      # смена, порт 3000
cd "/Users/user/Documents/Невский/manager-app" && npm run dev   # бэк-офис, порт 3100
```

Вход в бэк-офис на локальной базе: логин `vika`, роль владельца. Пароль выдан заново 07.08.2026 — он у владельца.

```bash
cd manager-app && npm run manager:list                    # кто заведён
cd manager-app && npm run manager:password -- vika        # забыли пароль — выдать новый
cd manager-app && npm run manager:add -- "Имя" логин owner  # завести человека
```

Пароль **восстановить нельзя** — в базе только необратимый отпечаток. Забыли — выдаём новый, других способов нет.

*В локальной базе есть отключённая учётка `checkbot` — её заводили 07.08.2026 для проверки экрана исправлений. За ней числятся правки, поэтому она отключена, а не удалена: удалить человека значит унести его след.*
