**Три находки, которые важнее самих процентов:**

1. **Сервисный сбор складывают в общую сумму чаевых, а не в его блок.** За 30.07 бумага даёт «ВСЕГО» 57 568 ₽ вместе со сбором 6 601 ₽ — и ровно 57 568 ₽ стоит в Google-таблице, где блок сбора пуст. Сбор занимает **16–17 % суммы в июне и начале июля против 5 % в августе**, поэтому любой расчёт «как записано» врёт. Считать только на очищенных цифрах.
2. **Комиссия Сбера — 8 %, и платит её персонал**, потому что настройка на терминале стоит по умолчанию «с сотрудника». Это ~59 тыс. ₽ в месяц. На QR гостя спрашивают — и 85–92 % соглашаются платить сами.
3. **Кнопки на терминале — 10/15/20 %, а не 9/14/18.** Сбер в колонке «% от суммы чека» показывает процент от суммы **после** вычета комиссии: 10 × 0,92 = 9,2 → «9». Восстанавливается по точному отношению чаевых к чеку.

**Метод расшифровки рукописного, который сработал.** В каждом листе своя арифметика: нал + сбор + QR + безнал = «ВСЕГО», отдельно «ОТЧЕТ» − «СТАФФ» = «ИТОГ». Расшифровал → прогнал контроль → где не сошлось, перечитал цифру. Из 68 листов разошёлся один. Без такой проверки чтению почерка верить нельзя.

**Хвосты, мелкие:**

- нет листов за **5 и 12 июля** — единственный пробел в окне;
- лист за **25.07** расходится на 274 ₽, неверно прочитаны наличные в одной колонке;
- выгрузка Quick Resto за июль–август **не нужна**, владелец сказал 10.08, что данных достаточно. За март–июнь она лежит в `~/Downloads/shift-aggregate-report-*`: там есть «Чеков Приход» и «Средний чек» по каждой смене, привязанные к смене, а не к календарному дню.

## Как поднять на своём компьютере

```bash
cd "/Users/user/Documents/Невский/mini-app" && npm run dev      # смена, порт 3000
cd "/Users/user/Documents/Невский/manager-app" && npm run dev   # бэк-офис, порт 3100
```

Вход в бэк-офис на локальной базе: логин `vika`, роль владельца. Пароль выдан заново 07.08.2026 — он у владельца.

```bash
cd manager-app && npm run manager:list                    # кто заведён
cd manager-app && npm run manager:password -- vika        # забыли пароль — выдать новый
cd manager-app && npm run manager:add -- "Имя" логин owner  # завести человека
```

Пароль **восстановить нельзя** — в базе только необратимый отпечаток. Забыли — выдаём новый, других способов нет.

*В локальной базе есть отключённая учётка `checkbot` — её заводили 07.08.2026 для проверки экрана исправлений. За ней числятся правки, поэтому она отключена, а не удалена: удалить человека значит унести его след.*
