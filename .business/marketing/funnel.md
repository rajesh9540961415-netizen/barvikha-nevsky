# Воронка

> ⚠️ **Цифр нет.** Конверсии по этапам не измеряются.

## Как выглядит качественно

Карты или сарафан → карточка заведения, рейтинг и отзывы → визит → повторный визит на личном сервисе.

Подробнее по этапам — [`../audience/journey.md`](../audience/journey.md).

| Обращения / брони |  |  |
| Визиты |  |  |
| Повторные визиты |  |  |

## Где проседает

Нет данных. Единственный известный ориентир — постоянных и новых гостей примерно поровну.

## Что мешает измерять

Не зафиксировано, где вообще ведётся учёт (см. [`../goals/kpi.md`](../goals/kpi.md), раздел «Где данные»). Пока это не решено, воронку не посчитать.
