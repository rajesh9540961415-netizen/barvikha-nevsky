## Что есть и чего не хватает

Служебная дверь `manager-app/src/app/api/tips-fix/route.ts` (ключ
`TIPS_FIX_KEY`) умеет: `замена`, `отмена`, `бар`, `состав`, `склейка`.

**Не умеет двух вещей, без которых листы не внести:**

1. **Завести смену.** `состав` правит уже существующую смену (`readDay`
   → «смены за этот день нет»), а `добавитьЗапись` без смены отказывает
   («сначала соберите состав»). За 13–18.10 смен в базе нет вовсе.
2. **Завести запись официанту зала.** `бар` пишет только в общий котёл
   кальянного бара.

## Как вносим лист

| Строка листа | Что делаем |
|---|---|
| имена в шапке зала | состав смены (`crew`) |
| «Админ», «Кассир» в шапке справа | `admin`, `cashier` смены |
| НАЛ / СЕРВ. СБОР / Б/НАЛ | по записи на официанта: `cash` / `service` / `terminal` |
| QR | **не вносим** — довёз робот из Telegram (`qr_tips`), разносит кассир. Сверить суммы листа с поступлениями робота |
| СТАФФ | запись `staff` (вычет) |
| ВСЕГО, АДМИН, КАССИР, ОТЧЁТ, ИТОГ | **не вносим** — приложение считает само. Это проверка: посчитанное должно сойтись с листом |
| К/Б | `бар`, по видам денег |
