## Главный принцип: факт и план — это разные документы

**Решение владельца 08.08.2026.** Смешивать их нельзя, и это правило дороже любой формулы.

| | «Фин. свод» | Планирование |
|---|---|---|
| Что показывает | **факт месяца**: что реально уплачено и реально получено | что предстоит заплатить и получить |
| Налоги | по дате платежа, как ушло | размазаны по месяцам, как заработаны |
| Доход | по дате поступления | ожидаемый |
| Назначение | отчётность, сверка | решения: хватит ли денег, когда будет тяжело |

Повод для правила: 08.08.2026 в страницы «Фин. свода» за май и июнь была добавлена строка «рентабельность с выровненным налогом». Владелец справедливо возразил: выкладка хороша, но её место — в планировании, а свод фиксирует реальные суммы. Строку убрали.

**Не возвращать нормализацию в «Фин. свод».** Она живёт здесь.

## Что уже известно — фундамент для планирования

Всё проверено на данных за январь–август 2026, не оценки.

### Налоги

- **Средняя нагрузка — 12,45 % от выручки.** За январь–июль уплачено 17 901 592 ₽ при выручке 143 834 175 ₽. Это УСН плюс НДС, взносы и НДФЛ вместе.
- **Платятся рывками**, а не ровным потоком:

  | Тип месяца | Когда | Сколько |
  |---|---|---|
  | Квартальный транш УСН | январь, апрель, июль, октябрь | 4–5,5 млн, ≈ 8 % от выручки прошедшего квартала |
  | Годовой расчёт УСН | март | 4,1 млн в 2026 |
  | Обычный месяц | остальные | 450–900 тыс. (НДС 1/3 + взносы + НДФЛ) |

- Доля налога от выручки по месяцам 2026: янв 9,3 %, фев 11,6 %, **мар 23,0 %**, **апр 19,0 %**, май 2,1 %, июн 2,9 %, **июл 22,2 %**. Разброс десятикратный — сравнивать месяцы по факту бессмысленно.
- **У ИП Шалаевой другая налоговая ставка**, модель «8 % от квартальной выручки» к ней неприменима. Ставка пока неизвестна — [открытый вопрос](./2026-08-07-состояние-финучета.md).

### Что даёт нормализация

Заменив фактический налог месяца на 12,45 % от его выручки, получаем сопоставимую картину:

| | Май | Июнь |
|---|---|---|
| Рентабельность продаж по факту | 39,08 % | 38,53 % |
| **С выровненным налогом** | **28,69 %** | **29,10 %** |

Два месяца с разной выручкой (22,0 и 28,3 млн) дали почти одинаковый результат — это и есть проверка, что метод работает. **Настоящая экономика заведения ≈ 29 копеек прибыли с рубля выручки.**

### Календарь платежей — что известно о датах

| Дата | Что уходит |
|---|---|
| 10-е | зарплата / аванс |
| 15-е | аренда |
| 25-е | аренда, зарплата |
| 28-е | налоги |
| 30-е | зарплата за месяц |

Плюс движения наличных: **10-го и 25-го около 2 млн ₽ возвращаются из инкассации в кассу** под выплату зарплаты. В доход это не идёт — проверено 08.08.2026 по примечаниям к таблице выручки.

### Постоянные платежи, на которые можно опереться

- **Аренда** — ООО «Первый», ≈ 1,75–1,8 млн ₽ в месяц, стабильно.
- **Кухня** — ИП Московкина Е. В., 4,0–6,1 млн ₽, растёт с выручкой.
- **Интернет** — ПАО «Ростелеком», ровно 11 773 ₽ каждый месяц.
- **Ежедневка** — ООО «Глобал Групп», 520–760 тыс. ₽.
- **Карта ООО** — 178–221 тыс. ₽ в месяц, из них две трети такси.

### Резерв на налоги

Копилка пополняется автоматически: **6 % с каждого поступления** на расчётный счёт уходит на депозит. Проверено: июнь 6,0 %, июль 6,1 %, август 6,0 %.

**Ставки не хватает.** На 08.08.2026 в копилке 268 874 ₽, к 28 августа нужно ≈ 974 244 ₽ — не хватает 705 370 ₽. К квартальному траншу разрыв кратно больше: 6 % покрывают примерно половину.

## Фазы

### [ ] Фаза 1. Платёжный календарь

Основная задача. Календарь на год вперёд, где рядом стоят **факт** и **ожидание**.

- [ ] Формат: строка = платёж, колонки — дата, контрагент, статья, сумма ожидаемая, сумма фактическая, статус
- [ ] Регулярные платежи вытащить из истории автоматически: контрагент, который платится каждый месяц примерно в одну дату и примерно одной суммой
- [ ] Разовые и сезонные помечать руками
- [ ] Налоговые даты подставлять по календарю, суммы — по модели
- [ ] Как факт приходит в выписке — подтягивать его в ту же строку и считать отклонение

### [ ] Фаза 2. Прогноз остатка и кассовых разрывов

- [ ] На каждый день вперёд: ожидаемый остаток = сегодняшний + прогноз поступлений − плановые платежи
- [ ] Подсветка дней, где остаток уходит ниже порога
- [ ] Тяжёлые даты по истории: 15-е и 27–31-е
- [ ] Учитывать, что зарплата в основном платится **наличными из кассы** — тревога только по банку даёт ложный сигнал (ошибка, допущенная 07.08.2026)

### [ ] Фаза 3. План на год

- [ ] Выручка по месяцам с учётом сезонности — брать из истории 05.2024–08.2026, 27 месяцев
- [ ] Расходы: постоянные из справочника регулярных платежей, переменные — долей от выручки
- [ ] Налоги по календарной модели, отдельно по каждому юрлицу со своей ставкой
- [ ] Сценарии: базовый, пессимистичный, оптимистичный

### [ ] Фаза 4. Норма отчисления в резерв

- [ ] Посчитать, какая ставка вместо 6 % реально закрывает квартальный транш
- [ ] Учесть, что у Шалаевой своя налоговая ставка
- [ ] Предложить владельцу изменить настройку в банке
